# .ai-context

โครงสร้างย่อของระบบ (อัพเดตเมื่อมีการเปลี่ยนแปลงสำคัญ)

## Stack
- Node.js + Express + EJS
- Bootstrap 5 + Bootstrap Icons (CDN), Sarabun font
- Session: `express-session` + `connect-mongo` (MongoDB store)
- Mock data ทั้งหมดอยู่ใน `data/*.js` ยังไม่ต่อ DB จริง

## Architecture (สำคัญ)
ใช้ **MVC pattern**: `routes → controller → render('main', {page, ...})` แล้ว `main.ejs` ทำ `include(page)` กับ fragment

```
routes/<resource>.js          เรียก controller method ล้วน ๆ ไม่มี logic
controllers/<resource>Controller.js   logic + render
data/<resource>.js            mock data, exports { mockX, ... }
views/main.ejs                main layout (sidebar + topbar) → include(page)
views/main-auth.ejs           layout สำหรับหน้า auth (ไม่มี sidebar)
views/<resource>/*.ejs        fragment ล้วน (ไม่มี <html>/header/footer include)
views/<resource>.ejs          fragment ระดับ root (เช่น dashboard.ejs)
```

**Naming**: resource ใช้ singular — `loan`, `payment`, `collateral`, `customer`, `auth` (ทั้ง file/URL/page key)
ตัวแปรที่เป็น array ยังเป็น plural — `mockLoans`, `loans.forEach()` (ตามหลัก English)

## Routes / Modules

| URL | Router | Controller | Pattern |
|-----|--------|------------|---------|
| `/` | `routes/index.js` | `indexController.dashboard` | refactored ✓ |
| `/loan` (list/apply/:id) | `routes/loan.js` | `loanController` | refactored ✓ |
| `/payment` (list/new/:receiptNo) | `routes/payment.js` | `paymentController` | refactored ✓ |
| `/collateral` (CRUD) | `routes/collateral.js` | `collateralController` | refactored ✓ |
| `/customer` (list/:id) | `routes/customer.js` | `customerController` | refactored ✓ |
| `/auth/login`, `/auth/logout` | `routes/auth.js` | `authController` | refactored ✓ (ใช้ `main-auth.ejs`) |
| `/reports/*` | `routes/reports.js` | — | **ยังเป็น old pattern** |
| `/settings/*` | `routes/settings.js` | — | **ยังเป็น old pattern** (`views/settings/_nav.ejs` + `_header.ejs`) |

### Page keys (ค่าที่ controller ส่งให้ `main.ejs`)
- `dashboard`
- `loan/index`, `loan/apply`, `loan/detail`
- `payment/index`, `payment/new`, `payment/receipt`
- `collateral/index`, `collateral/detail`, `collateral/form` (ใช้ทั้ง create/edit)
- `customer/index`, `customer/detail`
- `auth/login`

### Sidebar active pattern (`main.ejs`)
```ejs
<a class="nav-link <% if (typeof(page)!="undefined"&&(page=="loan/index"||page=="loan/detail")) { %>active<% } %>" href="/loan">
```
แต่ละเมนูเช็ก page ตรง ๆ (รองรับหลายค่าผ่าน `||`)

## Domain Logic
- **Loan ↔ Collateral**: 1:1 ต่อช่วงเวลา (1 หลักประกันค้ำได้ 1 สัญญา) — โครงสร้างพร้อมขยายเป็น many-to-many
- **Collateral status**: `ว่าง` / `ใช้ค้ำอยู่` / `ปลดแล้ว`
- **Loan status**: `อนุมัติ` / `รออนุมัติ` / `ปฏิเสธ` / `ปิดบัญชี`
- หน้า apply (loan) มี 2 mode: **เพิ่มใหม่** (default) / **เลือกจากคลัง** (filter status='ว่าง')
- Reports: `/reports/{summary,revenue,overdue,portfolio,collateral,customer}` — charts ใช้ progress bar / SVG donut (ไม่ใช้ Chart.js)
- Settings: 2-column layout, sub: `general`, `loan-products`, `fees`, `channels`, `notifications`, `users`, `security`, `system`

## Code Conventions
- `req.params` **ต้อง destructure** + ใช้ template literal เสมอ:
  ```js
  const { id } = req.params;
  return res.redirect(`/collateral/${id}`);
  ```
- ห้ามใช้ inline style ใน HTML ใหม่ (ของเดิมไม่ต้องแก้)
- ยกเว้นค่าที่ผูกกับข้อมูลจริง (สี, % progress) — ใช้ inline ได้
- Controller wrap ทุก action ด้วย `try/catch` แล้ว redirect บน error
- Status tabs: คลาส `.status-tabs > .status-tab` (responsive: pill บน mobile)
- `breadcrumb`, `page`, `title` ส่งผ่าน `res.render("main", {...})`
- ใช้ `const`/`let` (ไม่ใช้ `var`) ในไฟล์ใหม่
- ตัวแปลใช้ let ส่วน const ใช้ใน  require()

## Files ที่สำคัญ
- `app.js` — mount routers, session, MongoDB store
- `views/main.ejs` — layout หลัก (sidebar/topbar/include page)
- `views/main-auth.ejs` — layout auth (ไม่มี sidebar)
- `views/partials/header.ejs` + `footer.ejs` — layout เก่า (ยังใช้กับ customers/reports/settings)
- `public/stylesheets/style.css` — Sarabun, sidebar, status tabs, auth, settings, reports
